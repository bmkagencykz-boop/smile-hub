# Smile Sales Hub — мини-приложение Telegram

Хаб продаж для клиник: две ниши (стоматология, косметология), материалы с листанием страниц, бесплатные уроки, калькулятор потерь, самопроверка отдела, аудит, покупка через бота.

## Файлы
- `index.html` — оболочка, подключает Telegram WebApp SDK.
- `data.js` — весь контент: цены, ссылки на покупку, документы и страницы, уроки, отзывы, вопросы самопроверки. Менять здесь.
- `app.js` — экраны и логика (роутер по `#/…`, кнопки Telegram, просмотр страниц, видео, калькулятор, тест).
- `app.css` — стиль: светлый фон, акцент ниши (стоматология красный, косметология розовый).
- `media/` — ролики косметологии для бесплатных уроков (сжаты до 720p).

## Экраны
| Адрес | Что показывает |
|---|---|
| `#/` | приветствие по имени из Telegram, выбор ниши, бесплатное, аудит, автор |
| `#/n/stom`, `#/n/cosm` | ниша: вкладки «Папка», «Уроки», «Как работает», «Отзывы», «Купить»; внизу кнопка «Купить папку» |
| `#/lessons` | все бесплатные уроки по нишам |
| `#/calc` | калькулятор потерь: первичные обращения, % записи, цель, чек |
| `#/quiz` | самопроверка отдела: 10 пунктов, ответы сохраняются |
| `#/audit` | услуга аудита, связь с @thedmkr |

Покупка: кнопка открывает бота (`t.me/smilesalesbot?start=landing` для стоматологии, `?start=cosmo` для косметологии), дальше оплата Tribute, как на лендингах.

## Подключение к боту @smilesalesbot
Нужен HTTPS-адрес приложения (например GitHub Pages: `https://bmkagencykz-boop.github.io/smile-hub/`).

1. **Кнопка меню бота.** @BotFather → `/mybots` → @smilesalesbot → Bot Settings → Menu Button → Configure menu button → вставить адрес, название «Открыть хаб».
2. **Приложение по ссылке.** @BotFather → `/newapp` → выбрать бота → название, описание, картинка 640×360 → адрес → короткое имя, например `hub`. Ссылки:
   - `https://t.me/smilesalesbot/hub` — главная;
   - `https://t.me/smilesalesbot/hub?startapp=stom` — сразу стоматология;
   - `https://t.me/smilesalesbot/hub?startapp=cosm` — сразу косметология.
3. **Кнопка «Ознакомиться» в приветствии бота.** Inline-кнопка типа `web_app` с тем же адресом. В конструкторе ботов это кнопка «Открыть веб-приложение / Mini App».

Проверка вне Telegram: тот же адрес открывается в браузере, `?n=cosm` открывает косметологию.
